# LightLeads

Платформа сквозной аналитики рекламы и продаж: показывает, какая кампания, группа,
объявление и креатив в Meta и TikTok Ads приносят продажи и прибыль, а не только клики и лиды.

Полное ТЗ и план по фазам — в [PROMPT.md](PROMPT.md).

## Состояние: Фаза 0 — основа и дизайн

Готовы дизайн-система и все экраны на демо-данных. Бэкенда пока нет: данные генерируются
в браузере и сбрасываются при перезагрузке страницы.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
```

Чтобы открыть с телефона в той же сети Wi-Fi, возьмите адрес из строки `Network` в выводе
`npm run dev`, например `http://192.168.1.106:3000`.

```bash
npm run lint       # ESLint
npx tsc --noEmit   # проверка типов
npm run build      # сборка для Vercel
```

## Деплой

Сайт: https://lightleads-indol.vercel.app (Vercel, проект `lightleads`).

Каждый push в ветку `main` собирается и выкладывается автоматически. Если сборка из GitHub
падает с ошибкой `git_info_fail` («Git information retrieval failed»), переподключите
репозиторий и выложите напрямую:

```bash
npx vercel git disconnect && npx vercel git connect
npx vercel deploy --prod
```

## Стек

Next.js 15 (App Router) · TypeScript strict · Tailwind CSS 4 · shadcn/ui · Framer Motion ·
Recharts · lucide-react · zod · date-fns · libphonenumber-js.

## Структура

```
src/
  app/                    страницы (App Router)
    (app)/                кабинет: дашборд, кампании, креативы, лиды, продажи, AI, настройки
    (auth)/               вход и регистрация
    onboarding/           мастер подключения
  components/
    kit/                  дизайн-система: кнопки, карточки, деньги в двух валютах, бейджи, анимации
    shell/                каркас: сайдбар, верхняя панель, нижняя навигация, выбор периода
    charts/               графики
    features/             крупные блоки: добавление продажи, импорт, KPI, воронка, советы
    ui/                   компоненты shadcn/ui
  i18n/ru.ts              все тексты интерфейса (для kk/en добавить словарь того же типа)
  lib/
    mock/seed.ts          детерминированный демо-сид
    store.tsx             состояние демо; в Фазе 1 заменяется чтением из Supabase
    metrics.ts            все производные метрики: прибыль, ROMI, ROAS, CPL, CAC, конверсия
    analytics.ts          сведение расхода, лидов и продаж за период
    attribution.ts        связка продажи с лидом по телефону, поиск дублей
    currency.ts           конвертация по курсу на дату операции
    score.ts              рейтинг креатива 0–100 со сглаживанием
    rules.ts              правила-сигналы для AI-советов
    phone.ts              нормализация телефона в E.164
    csv.ts                разбор и проверка CSV для импорта
```

## Что в демо настоящее, а что имитация

Настоящая логика (перейдёт в следующие фазы без переписывания): нормализация телефона,
атрибуция с выбором модели и окна, поиск дублей, двойная валюта с курсом на дату операции,
расчёт метрик, рейтинг креативов, правила-сигналы, разбор CSV.

Имитация: вход и регистрация, подключение кабинетов, синхронизация, тексты AI-советов
(шаблоны вместо Claude API), чат (ответы на вопросы-подсказки), превью креативов
(сгенерированные обложки вместо файлов из Storage), курсы НБРК (сгенерированный ряд).
